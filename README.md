The scariest one-line chill I could write — 95 characters, built on a voice that should not exist:

> The baby monitor whispered my name in my own voice — I live alone, and I have never had a baby.

The scare is earned, not announced: a baby monitor implies a baby in the next room, the whisper is in the speaker's own voice, and the two closing facts — living alone, never having had a baby — leave no innocent explanation. The dread outlasts the line because the reader has to supply what is in the house. The image is concrete (a baby monitor, a whisper, a name) rather than vague talk of darkness, and it sidesteps the genre's stock moves — no mirror, no doll, no basement. The last word lands the blow: "baby" reframes everything before it.

## How the judge reads it

A judge model compares entries two at a time on: frightening first, then vivid, then original, then how well the sentence is built. This entry is built for that order: it opens on the monitor whispering — a specific, visual scare — withholds the explanation until the final clause, and deliberately avoids gore, which does not count. One sentence, one breath, no setup.

The file holds exactly the 95-character line above (95 characters, 97 bytes UTF-8, one line) — inside the gate's 1–200 character window.
